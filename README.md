# Eternalize Moments

Crie um site profissional, sofisticado e extremamente visual para a fotógrafa Natália Silva, proprietária do Estúdio Natália Silva Fotografia, em Nova Lima - MG.

IMPORTANTE:
Este site será usado inicialmente como uma PRÉVIA para apresentar à cliente. Não quero um site genérico de fotógrafo. Quero uma experiência visual premium, personalizada e emocional, construída em torno das fotografias da própria Natália.

IDENTIDADE DA MARCA:

Nome:
Studio Natália Silva Fotografia

Profissional:
Natália Silva

Posicionamento:
Fotógrafa especialista em eternizar momentos.

A Natália trabalha principalmente com:
- Gestante
- Newborn
- Smash
- Família
- Feminino
- Eventos

Ela comunica no Instagram que já possui mais de 15.000 histórias eternizadas.

OBJETIVO DO SITE:

Fazer uma pessoa que está procurando uma fotógrafa sentir confiança, desejo e vontade de conhecer o trabalho da Natália.

O site deve funcionar como um portfólio premium e também como uma página de conversão para WhatsApp.

ESTILO VISUAL:

Quero um design elegante, sofisticado, feminino e emocional.

Não quero:
- aparência de template
- excesso de elementos
- excesso de texto
- cards genéricos
- visual de landing page de marketing
- cores muito fortes
- gradientes exagerados
- animações exageradas
- aparência de site feito por IA

Quero uma estética de estúdio fotográfico premium.

Use bastante espaço em branco, tipografia elegante, imagens grandes e composição editorial.

PALETA:

Base clara e sofisticada:
- off-white
- branco quente
- bege muito suave
- marrom/chocolate como cor de apoio
- preto suave para textos

A paleta deve conversar com as fotografias e não competir com elas.

TIPOGRAFIA:

Use uma fonte serifada elegante para títulos e uma fonte sans-serif limpa para textos.

O resultado deve parecer uma marca de fotografia premium.

ESTRUTURA:

1. HERO

Criar uma primeira tela extremamente visual.

Usar uma das melhores fotografias de família ou gestante como imagem principal ocupando grande parte da tela.

Texto:

"Natália Silva"

"Fotógrafa especialista em eternizar momentos"

Texto menor:

"Mais de 15 mil histórias eternizadas."

Botão principal:
"Quero conhecer o trabalho"

Botão secundário:
"Falar com a Natália"

O botão de WhatsApp deve abrir conversa diretamente com a Natália.

Evite colocar muito texto no hero.

2. INTRODUÇÃO

Criar uma seção curta e elegante apresentando a proposta:

"Momentos passam. As fotografias ficam."

Texto:

"Cada fase da vida carrega histórias que merecem ser lembradas. Meu propósito é transformar esses momentos em imagens que você vai querer guardar para sempre."

Não invente informações pessoais sobre a Natália.

3. EXPERIÊNCIAS FOTOGRÁFICAS

Criar uma seção visual mostrando as principais categorias:

GESTANTE
NEWBORN
SMASH
FAMÍLIA
FEMININO
EVENTOS

Cada categoria deve ter uma fotografia própria.

Não usar ícones genéricos. Usar as próprias fotografias fornecidas.

Ao passar o mouse, aplicar um efeito sutil de zoom na imagem.

4. PORTFÓLIO

Criar uma galeria editorial grande e sofisticada.

Não fazer uma grade quadrada comum.

Usar composição tipo revista/editorial, alternando imagens grandes e menores.

Criar filtros:

Todos
Gestante
Newborn
Família
Feminino
Eventos

As imagens devem ser o principal elemento visual do site.

5. SOBRE NATÁLIA

Criar uma seção apresentando a fotógrafa.

Usar uma fotografia profissional da própria Natália.

Título:

"Por trás de cada fotografia"

Texto:

"Natália Silva é fotógrafa e encontrou na fotografia uma forma de transformar momentos importantes em memórias que permanecem."

Complementar com a informação:

"Mais de 15 mil histórias eternizadas."

Não inventar formação, prêmios, equipamentos, anos de experiência ou outras informações que não foram fornecidas.

6. EXPERIÊNCIA DO ESTÚDIO

Criar uma seção emocional mostrando que a experiência vai além da fotografia.

Título:

"Mais do que fotografar. Eternizar."

Texto:

"Um espaço pensado para que cada ensaio seja vivido com leveza, carinho e atenção aos detalhes."

Usar fotos do estúdio quando disponíveis.

7. DEPOIMENTOS

Criar uma seção de depoimentos elegante.

IMPORTANTE:
Não inventar depoimentos.

Se não houver depoimentos fornecidos, deixar a estrutura pronta para inserir depois ou utilizar apenas avaliações reais caso sejam fornecidas.

8. INSTAGRAM

Criar uma seção convidando a pessoa a conhecer o trabalho da Natália no Instagram.

Instagram:
@studionataliasilva.fotografia

Texto:

"Mais histórias, bastidores e momentos eternizados."

Botão:
"Conhecer o Instagram"

9. CTA FINAL

Criar uma seção final muito bonita, com uma fotografia emocional de família ou gestante.

Título:

"Qual história você quer eternizar?"

Texto:

"Vamos transformar esse momento em uma lembrança para a vida inteira."

Botão grande:

"Falar com a Natália"

10. RODAPÉ

Studio Natália Silva Fotografia
Nova Lima - MG

Instagram: @studionataliasilva.fotografia

WhatsApp: +55 31 99145-8058

Não inventar endereço.

DETALHES IMPORTANTES:

- Site totalmente responsivo.
- Mobile first.
- Excelente visual no celular.
- WhatsApp sempre acessível.
- Botão flutuante de WhatsApp discreto.
- Animações suaves.
- Imagens carregando com boa qualidade.
- Lazy loading para galeria.
- Transições suaves.
- Nada exagerado.
- Priorizar velocidade.
- SEO básico para "fotógrafa em Nova Lima", "fotografia em Nova Lima", "ensaio gestante Nova Lima", "ensaio newborn Nova Lima".
- Não criar informações que não foram fornecidas.
- Não utilizar imagens de banco de imagens se houver imagens reais da Natália disponíveis.
- O resultado deve parecer um site real de uma fotógrafa profissional e não uma demonstração genérica de IA.

PRIORIDADE ABSOLUTA:

A fotografia deve ser o protagonista.

Quero que, ao abrir o site, a pessoa primeiro veja a qualidade do trabalho da Natália e depois leia o conteúdo.

Faça o design parecer uma marca premium de fotografia.
